## Sobre a atividade

Este projeto reúne cinco exercícios desenvolvidos em TypeScript, com foco na aplicação de tipos, funções, estruturas de controle, manipulação de dados e interação com páginas HTML.

## Exercícios

- **Exercício 01:** Cálculo de média e situação do aluno.
- **Exercício 02:** Cálculo de consumo de energia elétrica.
- **Exercício 03:** Simulação de parcelamento.
- **Exercício 04:** Cálculo de economia até atingir uma meta.
- **Exercício 05:** Fechamento de compra com descontos e cupom.

## Tecnologias utilizadas

- HTML5
- CSS3
- TypeScript
- JavaScript gerado a partir do TypeScript

## Como executar

Abra o arquivo `index.html` pelo Live Server no Visual Studio Code para acessar a página inicial e navegar pelos exercícios.
